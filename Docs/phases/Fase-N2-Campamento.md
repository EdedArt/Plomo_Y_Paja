2. **`LoboBossController`** (`Scripts/Characters/Lobo/`), states:
   - **Dormant:** behind his desk at `Anchor_LoboStart`, `idle`, ignores the player.
   - **Intro:** player enters `Trigger_Salon` → `lobo_combate_01`, stands up.
   - **Phase 1:** moves between `Anchor_LoboCover_*` (≈ 2.5 m/s, never through the player), cover → peek → **0.4 s telegraph** (aim frame + small glint) → burst of 3 shots 0.15 s apart → back to cover; cooldown 2.0–2.8 s; 30 % hit chance (15 % if the player runs), 7 damage per bullet. Barks from guion §3, never overlapping, ≥ 4 s apart.
   - **At ≤ 50 % HP:** `call_01` + `lobo_combate_04`; the 2 reinforcements spawn at `Anchor_Refuerzo_A/B` already chasing; he keeps to the desk as cover. **Phase 2:** cooldown ×0.75.
   - **Kneel (L6):** at the kneel threshold (serialized, default 15 % HP): `hit_01` 0.35 s, `lobo_cae_01`, drops his gun (just a prop), kneels where he is (or the closest reachable floor point) → **Kneeling:** `rodillas` pair with lip-sync; `lobo_rodillas_01` once with LOS; player ≤ 3 m + LOS → `OnConfrontationRequested` (N2.3). Reinforcements still alive stop attacking and surrender.
   - **Shot while kneeling, before the scene:** `death_01`, `LoboState = Dead`, normal kill AI line, then the finale after 2.5 s (N2.3 step 5; until N2.4 exists, log the resolved final).
   - Hitbox shrinks in cover (desk and columns block bullets both ways). Billboard reused; root ×1.2; `kneelScale`.
   - **Balance targets:** he kneels after ≈ 9–11 revolver body hits or ≈ 4–6 point-blank shotgun blasts. All numbers serialized; report HP chosen and time-to-kill estimates with the current weapon values and the ammo available before/inside the hall (L5).
3. **`GameStateTracker`:** `LoboState { None, Dead, Pardoned }` with event (reuse the existing "lobo killed/spared" field if there is one), included in the AI context.
4. **Shots:** through `EnemyGunfire` with `MuzzlePointSet_Lobo` (fallback point) if HUD.2 is closed; otherwise the same hitscan path Centavo uses today, and report it for HUD.2.
5. Player death during the fight → normal restart (reload `Campamento`), boss state reset.
